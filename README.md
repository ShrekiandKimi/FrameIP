# Сервис доставки готовой еды

## Назначение

Приложение для оформления и отслеживания заказов доставки готовой еды из кафе и ресторанов: клиент выбирает блюда, оформляет заказ, а сервис рассчитывает стоимость, применяет скидку и назначает свободного курьера для доставки.

## Целевая аудитория

Клиенты, заказывающие готовую еду с доставкой на дом или в офис.

## Предметная область

Сфера доставки готовой еды: оформление заказов, расчёт их стоимости, взаимодействие клиентов с курьерами и отслеживание статуса доставки.

## Основные сущности

- Клиент (Client) — пользователь, оформляющий заказ
- Заказ (Order) — набор выбранных блюд с количеством, стоимостью, курьером и статусом
- Блюдо (Dish) — позиция меню, доступная для заказа
- Курьер (Courier) — исполнитель, доставляющий заказ клиенту

## Основные функции

- `add_dish`, `find_dish`, `filter_dishes_by_price`, `sort_dishes` — работа с меню (добавление, поиск, отбор и сортировка блюд по цене)
- `calculate_order_total` — подсчёт стоимости заказа по выбранным блюдам
- `apply_discount` — расчёт стоимости заказа с учётом скидки при крупном заказе
- `get_delivery_cost` — расчёт стоимости доставки
- `create_order`, `cancel_order` — оформление и отмена заказа
- `assign_courier`, `is_courier_busy` — назначение свободного курьера на заказ
- `get_order_status` — проверка статуса доставки заказа
- `get_unique_clients`, `get_total_revenue` — статистика по заказам

## Структура проекта

- `main.py` — точка запуска, меню приложения;
- `dishes.py` — функции для работы с меню (блюдами);
- `orders.py` — функции для оформления, отмены и обработки заказов;
- `storage.py` — сохранение и загрузка данных в формате JSON;
- `utils.py` — вспомогательные функции безопасного ввода;
- `data/` — файлы данных (`dishes.json`, `orders.json`);
- `tests/` — автоматизированные тесты pytest.

## Формат хранения данных

Блюда (`data/dishes.json`) хранятся списком словарей с полями `id`, `name`, `price`.

Заказы (`data/orders.json`) хранятся списком словарей с полями `id`, `client_name`, `items` (словарь «id блюда → количество»), `total`, `courier`, `status`.
